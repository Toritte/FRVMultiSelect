FRV MultiSelect v0.1.0 — Toritte
Select different available FRV variants together in your stratagem loadout.

Requires Bingus Shared Loader v15 / API 1, downloaded separately:
https://ayakamods.com/mods/bingus-shared-loader.3861/
Official instructions: https://github.com/CowboyBingus/BingusSharedLoader
The loader is not bundled with this mod.

Installation:
1. Fully close Helldivers 2.
2. Disable Vehicle MultiSelect, the combined version.
3. Import this mod and Bingus Shared Loader into Arsenal or HD2MM and enable both.
4. Follow the loader's priority instructions. In Arsenal's default priority,
   put the loader last; with first-mod priority enabled, put it first.
5. Deploy and restart the game.

Optional: enable Exosuit MultiSelect v0.2 alongside this mod for both FRV and
exosuit multi-selection. FRV MultiSelect works without that optional mod.
Do not enable combined Vehicle MultiSelect at the same time.

Keeps the normal four slots. Does not unlock equipment, duplicate the same
stratagem or change cooldowns and call-in limits.
Supported Steam build 24826606 / EXE 1.8.45317.0.
Game updates may require a mod update.

Uninstall: fully close the game, disable this mod, purge and redeploy remaining
mods, then restart. Keep the loader if another enabled mod needs it.
